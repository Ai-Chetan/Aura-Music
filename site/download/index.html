Download the latest APK ↓

Install in 3 steps

  1. Download the APK. Open the releases page on your phone and download the newest .apk file (the Android app file).
  2. Allow the install. Android will ask you to allow installs from your browser (or file manager) once — this is normal for direct APK downloads.
  3. Open Aura and take the tour. A skippable first-launch tour runs over the real UI, with starter tracks you can download in the background.
Updates: Aura will not update itself silently. Check the releases page (or Watch the repo) for new versions and changelogs, then install the new APK over the old one — your library and tags are kept.

Before you install

Is Aura really free?

Yes — completely free, forever. No premium tier, no locked features, no paywalls, no ads. The code is MIT-licensed and open source on GitHub — contributors welcome (how to contribute).

Which Android versions are supported?

Android 8 and newer. If your device is older, the app file won't install — check Android details.

Is the APK safe?

The APK is built in the open from the public source. Aura requests only Internet, foreground media playback, and (on Android 13+) notifications — see the privacy notes. Only download from the official releases page linked here.

A note on saving audio

Aura is a private, on-device player — not a music provider. It doesn't own any songs and claims no rights over them: all music and artwork belong to their respective artists, labels, and rights holders. Aura only keeps what you choose on your phone for offline listening, with no sharing built in. Only keep content you own or have permission to keep, and never redistribute downloaded files.

Who owns the music? Who made Aura?

No songs belong to Aura — every right stays with its respective owner (YouTube™ is a trademark of Google LLC). Aura is developed by Ai-Chetan for the open-source community under MIT.
